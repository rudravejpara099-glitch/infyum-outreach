# Start here

This repository has two audiences. Pick yours:

**1. You want to USE the Instagram outreach (no coding): this is Phase 1, a finished kit.**
Read `phase1/GUIDE-FOR-CLAUDE.md` completely and follow it. It sets the user up, guides them step by step, and runs the outreach through their own Chrome. Do not read the rest of the repository, and **do not edit any file in it**: everything personal goes in the user's own folder `~/INFYUM-Phase1/`. If the user just says "start" or "set me up", begin with the guide's onboarding.

**2. You are a developer or AI agent working on the Phase 2 web app (`app/`, `lib/`, `worker/`, `extension/`).**
Read `AGENTS.md`, then `HANDOFF.md`.
